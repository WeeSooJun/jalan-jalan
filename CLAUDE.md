# CLAUDE.md — Jalan-Jalan

Singapore park-connector hiking + hawker food + cheap-attractions web app.
Live: **https://weesoojun.github.io/jalan-jalan/** (GitHub Pages, deployed from `main`).
Personal project for weekend hikes — mobile Safari is the primary target; test UX decisions against "one thumb on a phone, outdoors".

## Commands

Always use `corepack pnpm`, never bare `pnpm` — Homebrew's pnpm is 9.x, the project pins pnpm 10 via `packageManager` in package.json.

```bash
corepack pnpm install            # frozen by CI; install scripts are blocked by design
corepack pnpm dev
corepack pnpm build              # tsc typecheck + vite build → dist/
python3 scripts/fetch_routes.py  # regenerate src/routes.json (only when ROUTES waypoints change)
```

There is no test suite. Verification = `corepack pnpm build` passing + eyeballing `corepack pnpm dev`.

## Architecture

- Vite 6 (`base: "/jalan-jalan/"`) + React 19 + TypeScript strict + react-leaflet 5 / leaflet 1.9.4. Runtime deps are exactly: react, react-dom, leaflet, react-leaflet. Adding a dependency is a decision, not a default — the owner chose pnpm + minimal deps specifically for supply-chain safety (`minimumReleaseAge: 4320` in pnpm-workspace.yaml delays new releases 3 days; keep it).
- `src/data.ts` — ALL app data: trails, GEO coords, ROUTES waypoints, curated notices (TRAIL_ALERTS, NEW_PARKS, COMING_PARKS), hawker-cleaning fallback dates. Edit data here and nowhere else.
- `src/routes.json` — BRouter-snapped real trail polylines, generated by `scripts/fetch_routes.py`, committed. Regenerate after changing ROUTES waypoints in data.ts.
- `src/lib/` — maps.ts (Google/Apple URL builders, `trailGeometry()` = routes.json with waypoint fallback), kml.ts (KML export for My Maps), clean.ts (live NEA cleaning-dates fetch from data.gov.sg with baked fallback), photos.ts, store.ts (localStorage).
- `src/components/` — TrailMap.tsx (the Leaflet map: OneMap + Esri layers, divIcon pins, rich popups, locate control) + five views + App.tsx. Navigation is currently plain React state in App.tsx (no URL routing yet — see Pending).
- `public/imgs/`, `public/fimgs/` — Wikimedia Commons photos; credits live in `src/data_img_meta.json` / `src/data_fimg_meta.json` and MUST stay displayed in-app (CC licence requirement). Esri satellite layer requires the "Esri, Maxar, Earthstar Geographics" attribution; OneMap tiles require "OneMap © Singapore Land Authority".
- `legacy/` — pre-React builds (claude.ai artifact + static single-file site). Reference only; never edit as part of app work. The old artifact still exists at https://claude.ai/code/artifact/c5a8cfbf-0921-42fa-bd1a-827dce4bd59e and the weekly refresh routine `trig_01TPJ8aCTu7wkEoiPzAcA37r` is DISABLED (see README).

## Hard-won gotchas

- **Waypoints must be on routable land.** BRouter silently routes around water/fenced areas, producing absurd detours (a point inside Changi Airport's fence once added 18 km). `fetch_routes.py` routes leg-by-leg and falls back to a straight segment when a leg exceeds 2.5× straight-line + 0.5 km — if you see straight segments in output, check the waypoint, don't trust the guard to save the map.
- **Routed km ≠ listed km, intentionally.** `Trail.km` is the trail-only planning number; routes.json traces MRT-to-MRT. Don't "fix" one to match the other.
- **Leaflet's overlay pane is plain SVG in the DOM.** A global CSS rule targeting `svg` (e.g. the old `.mapbox svg{...}`) silently breaks polylines while tiles and divIcon pins keep working. Scope any SVG styling tightly.
- **No page-jump on pin tap.** Marker taps must not scroll the page (the old tap-to-scroll behaviour was hated on mobile). Popups link down via the "Details ↓" anchor instead.
- **Popups over panels.** Owner prefers info in map popups (photo, price, external links) over anything that moves the viewport.
- Leaflet's default attribution prefix includes a flag emoji; it's stripped via `attributionControl.setPrefix` in TrailMap.tsx — keep that if touching attribution.
- data.gov.sg datastore_search sends CORS `*`, so the NEA fetch works client-side; if it ever breaks, the app silently falls back to `CLEAN_BAKED` in data.ts (update `DATA_ASOF` when refreshing it).

## Pending / roadmap

- **URL routing** (owner-approved, not yet built): hash-based routes so the phone back-gesture goes trail-detail → list (`#/`, `#/trail/:id`, `#/makan`, `#/see`, `#/updates`, `#/day`). Hash routing chosen because GitHub Pages project sites 404 on deep links with history routing unless a 404.html hack is added. Weigh react-router vs hand-rolled hash sync against the minimal-deps stance.
- **Street view**: embedding real Google Street View needs the Maps JS API + billing key (against the keyless architecture). Keyless alternative: per-point pano links `https://www.google.com/maps/@?api=1&map_action=pano&viewpoint=<lat>,<lon>` in popups.
- Restore weekly auto-refresh of curated data blocks (see README "Weekly auto-refresh" section for options).
